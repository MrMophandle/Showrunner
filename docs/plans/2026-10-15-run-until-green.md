# Run Until Green Implementation Plan (Plan J)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The script gate opens only on a green panel. After every revision the seven reviewers run again, and revise-then-review repeats until every reviewer passes; the only stop is the weekly quota ceiling, after which the operator's Resume continues the loop. Reviewers converge because each one judges only whether its own prior issues are resolved, and the gate's message, the Board and the Run view say which round the run is on and what it has cost.

**Architecture:** The loop is the gate-rejection path the engine already has (inventory J-01, J-02): a new `panel` step kind evaluates the reviewers' verdicts and, when any fails, writes `step_reset` for the round's ten steps and restarts the pass, exactly as a rejected gate does; its idempotence anchor is its own last completion and a round counter in the reset's `by`. The prior verdicts travel through a `panel_round` event the trigger writes before it resets, which the agent executor renders into the reviewers' and the writer's prompts as `{{prior.<id>}}`; the round count, the cumulative cost and the weekly figure ride on the same event, so the gate message, the console and the stop rule all read one record. `revise` becomes one fresh writer call per round with no sentinel (the panel is the arbiter; J-21's wedged shared session cannot recur). The weekly figure comes from the SDK's usage call on every query (183 ms, J-20), attached to every `agent_result`. The reviewers' prompts and schemas gain the pass rule, the citation format, a non-failing `notes` field and the prior-verdict section that `canon-review-script` already has (J-11).

**Tech Stack:** TypeScript 5 (strict, ESM, NodeNext), vitest 4; `@anthropic-ai/claude-agent-sdk` 0.3.283; Hono 4, React 18 for the console; the prompt templates under `tools/templates/prompts/` with their harness; the show instance's copies under `~/GitHub/DeadLight2/prompts/` (a show-side pull request).

**Spec:** `docs/specs/2026-09-25-console-rewrite-design.md` §4.2 (the worker owns the run), §6.5–§6.9 (the log is the record), §7.4 (no show's name in the engine); Plan I's deferred record for the usage-limit rule; **the inventory `docs/plans/2026-10-15-plan-j-inventory.md` (27 findings) is the measurement this plan argues from.**
