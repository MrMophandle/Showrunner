# The Establishing Shot — rulings and deferred items

Companion to `docs/plans/2026-11-04-the-establishing-shot.md` (spec `docs/specs/2026-11-04-the-establishing-shot-design.md`). Written 2026-11-04 from the plan's SDD ledger. Every ruling below was made by the controller during execution; every deferred item is work the plan did not do, with what it costs to leave.

## Rulings

- **R-01 The lint's `SHOTS_BAD` line carries the reasons.** The fix agent reads only a step's result, which is its last stdout line, so `shot-list-check.py --report-only` ends with `SHOTS_BAD <n> shots: <ids> — <reason>; <reason>`; the reasons also go to stderr. (Pre-flight scan, Task 2.)
- **R-02 A 402 keeps the renderer's status grammar.** `nanobanana.generate_image` returns `error:<message> — <CREDITS_LINE>` for a depleted balance, because the renderer branches on the `error:` prefix; `"ok"` stays lowercase. (Task 1 quiz.)
- **R-03 The purge grep is the plan's, at the end of Task 5.** Task 1's in-scripts grep excluded `design-visual.py` and `image-sheet.py` (Task 2's files); Task 2's grep over the scripts package covered five extra files (`shot-sheet.py`'s `type` branches, the fixtures' ambient shots, `ambientPromptScaffold` in the fixture config, one historical comment).
- **R-04 The lint's test fixture is the suite's show fixture.** The plan's inline config lacked the loader's required keys (`showSlug`, `promptsDir`, `models.*`, `airMap`, `output.nasRoot`); the tests build on `scripts/tests/fixtures/showrunner.json` through the conftest `show_root` pattern.
- **R-05 The image sheet's casting-directory line is gone with its test.** It stated the local-versus-nano division of labour and told the reader to build a shot from a character's sheet, neither of which an establishing shot does.
- **R-06 An establishing shot may name its place (spec amended 2026-11-04, commit 48ae937).** Rule 2 forbids person kinds only (`character`, `human`, `creature`, `species`); a location or ship may be named and, when it has a `face.ref`, its key must be in `refs` so the render conditions on the place's reference; a person-kind ref on an establishing shot is BAD. Found by Task 2's review: without it, an establishing shot of Coalvane could not say Coalvane. Cost if wrong: a place's look drifts when the agent forgets the ref, and the lint makes that one fix-agent round.
- **R-07 The script is an input of both lint steps** (commit 07c9ccc). The lint reads the script's scene headers, and the runner serves a script step from cache when its declared inputs' hashes match, so a script edited between attempts would have left a new scene unchecked. Found by Task 3's implementer.
- **R-08 `## The establishing shot` of `Canon/visual-style.md` is a required bible section** (commit 0eea0c6). The verbatim visual-direction template cites the heading and the templates test refuses an uncited heading, so the row was added; `bible-check` and the console's Bible page name it when absent. The `bible-ready` guard does not check sections (the whole-branch review's first finding corrected the plan's claim that it did), so the show-side migration adds the section before the rerun rather than being stopped over it. The "Mandatory prompt scaffolding" row stays, cited by no template since 2026-11-04, because the section is where an author states the constants the renderer appends.
- **R-09 `visual.refs` stays in the init scaffold.** The key is Plan L2's to retire (`engine/src/show-config.ts`'s row says so); this plan removed only the three local-renderer keys.
- **R-10 A showrunner-made shot is never audited.** The audit loop runs before the gate and a hand-made PNG arrives after it; spec §4's order, accepted: Ryan sees his own shot. Cost: a watermark or a defect on a hand-made still reaches the timeline unjudged.
- **R-11 The console's walkthrough fixture names steps the pipeline has.** `seed-show.mjs`'s s02e04 run log renames `image-generate` to `nano-banana-generate` and the `amb-NN` shot ids to `sN-establishing`; the "eight gates" prose at four sites says seven. (Task 5.)

- **R-12 The whole-branch review's rulings (2026-11-04, eight findings).** `bible-ready` does not check sections, so the plan's claim that it would stop a show lacking `## The establishing shot` was corrected to what is true: `bible-check` and the Bible page name it (F1). An added place-only shot is legal: the engine's shot is `s<n>-establishing` and Ryan's additions may be of either type under other ids, so the lint no longer rejects a second establishing shot in a scene (F2, spec §2.1/§2.5). A shot Ryan makes by hand is never face-checked, so the lint's remedy "set source to showrunner" can be followed (F3). The renderer's docstrings and spec §3.2 state that an establishing shot's place refs condition the render (F4). The three renderer steps opt out of the step cache through `ScriptStep.cache: "never"`, because the renderer is idempotent and a cached completion would leave a PNG the audit deleted unrendered after a manual reset to the first audit (F5). Prose naming the retired gate with a space, the padded ids in a test fake and the spec's examples, and a comment's "forty PNGs" were corrected (F6–F8).

## Deferred

- **A console form on the image gate to add a shot to a scene** (spec §11). Until then a rejection note ("scene four: add Vale at the long table, refs vale") or a hand-written entry with `source: "showrunner"` is the mechanism.
- **Plan L2, the casting stop, re-planned against spec §7:** a voice for every new speaker, a face only when Ryan asks for a character shot of them; `refs-ready` demands no face since commit f394319.
- **The cast-name match is whole-word on the entry's name and key**, so a cast entry whose name is a common noun (a character named "Lamp") makes the lint flag every establishing brief that uses the word. Accepted as spec §2.5 rule 2's design; the fix agent reads the reason and rewrites around the word. Cost: one fix-agent round per collision.
- **Shot ids are unpadded (`s1-establishing` … `s12-establishing`)**, the lint's form, so a directory listing sorts `s10` to `s12` before `s2`. The timeline and the sheet order shots by the list, not by name; the console's contact sheet reads the images directory, so its order is the listing's. Cosmetic; a zero-padded form would touch the lint, its tests, the templates and the fixtures together.
- **A non-list `refs` on an establishing shot** is treated as no refs rather than reported; spec §2.5 rule 4 does not list the key's type among the shape checks.
- **The s02e04 walkthrough run log in `console/test/fixtures/seed-show.mjs`** is a thin version of the new image stage (one render event, one verdict, no lint or audit-loop events). No test reads it; a browser walkthrough of the image stage would want the full event sequence.
- **`tools/show-data/deadlight-overrides.json`** still names the retired scripts; it is the Archon port's data for `extract-prompts`, historical, and excluded from the purge grep.
- **`scripts/image-qc.py`**, an advisory histogram screen the pipeline never called, is deleted with the local renderer; its measured history (a low-key show's first cut read as too dark; a mean-brightness gate failed correct space shots) lives only in git now.
- **Ryan's Qwen-Image model caches** under `~/.cache/huggingface/hub/` (`models--Qwen--Qwen-Image`, `models--Qwen--Qwen-Image-Edit-2509`) are his to delete; nothing in the engine reads them after this plan.
- **The show's cast index files Cricket under kind `motif`** (seen in the 2026-11-01 build table). Cricket is a character; under R-06 a `motif` entry is a non-person kind, so a brief naming Cricket would pass the lint and the renderer would draw him uncast. The show-side migration (Task 7) sets the kind to `character`.
- **`console/test/runs.test.ts:39` flaked once** during the fix wave's re-review (a `setTimeout`-based `waitFor` poll in the run store's filesystem-watch tests) and passed on every rerun; the file was last touched before this plan. Cost: a red suite on a loaded machine until the poll is made deterministic.
